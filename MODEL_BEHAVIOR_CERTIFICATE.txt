STREAMING GUARDIAN — LEGACY CERTIFICATE SUPERSEDED

The previous version of this file contained performance and robustness claims
that were not adequately supported by the checked-in test suite. In particular,
the old malformed-input check skipped None and string values instead of passing
them to the detector. Its unconditional PASS labels must not be relied upon.

This file is intentionally not a fresh performance certificate. After checking
out a specific source revision and installing the supported test dependencies,
run:

    python -m benchmarks.generate_certificate

That command generates a scoped empirical behavior report and directly tests
rejection of malformed and non-finite scalar inputs. It does not establish a
universal false-alarm probability, general detection guarantee, or performance
across all operating regimes.

For scenario metrics with explicit denominators, run:

    python -m benchmarks.benchmark_runner

The benchmark distinguishes pre-change false-alarm trial probability,
pre-change alarm-sample rate, post-change detection probability, and detection
delay conditional on detection. Results remain empirical and scenario-specific.
